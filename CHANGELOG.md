# Changelog

All notable changes to Narravit are documented in this file.

## [0.1.0] - 2026-09-24

### Added

- The `session-preparation` skill for producing editable session drafts from campaign notes and a
  GM-selected Markdown template.
- A bundled, attributed session-preparation template and an example science-fiction campaign.
- A manual acceptance record covering complete-draft review, factual corrections, rules grounding,
  unresolved questions, and separation between session drafts and campaign facts.
- Installation through the open Agent Skills CLI with
  `npx skills add darklight3it/narravit --skill session-preparation`.
