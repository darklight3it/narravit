# Session request

Prepare a two-hour, system-neutral session about the courier ship Mothlight
arriving at Halcyon Ring with a sealed case. Focus on negotiation, investigation,
and a difficult choice. Save the result as a draft for GM review.

Party context:

- The pilot wants to keep the Mothlight independent.
- The mechanic has a personal connection to Port Meridian.
- The group prefers negotiation and hard choices to tactical combat.
